# SB2 observations

`measurements.jsonl` contains the compact CLI results (pass/fail/unsure, peak cd, lm in window, aim, per case). The per-run raw `flux.js trace`/`solve` JSON files (~150 files, 2.8 MB) were pruned from the branch by the tester; rerun the bench to regenerate them (they are written under `<phase>/`). Kept: this README, `build-progress.md`, `measurements.jsonl`, `rebuild.json`, and `placement/` scenes + `commands.jsonl` for direct replay.

Run from the repository root:

```sh
node tools/sealed-beam/v2-bench.js placement
node tools/sealed-beam/v2-bench.js bare
node tools/sealed-beam/v2-bench.js lens --lamps 7,5.75 --beams low,high --models sealed,h4 --evals 150 --tuneRays 100000
```

The bench appends summary rows; use a new output checkout or keep the run boundaries when repeating it. Lens intermediate input/solved/trace-scene JSON files are generated by the bench and omitted here to avoid duplicating the saved final examples. Those final scenes are `examples/sealed-beam-v2-*.json`. The placement and bare scenes are retained for direct replay. `rebuild.json` records the byte-identical final-example checks; the same check is automated in `tests/sb2-node.js`.

The final lens runs use explicit high-beam starting settings and corrected fractional-part scatter for negative flute indices. The SB2 report records the inherited high-default substitution and negative-remainder issues discovered during development; both are fixed in v2 and preserved in v1.

These are CPU observations at one seed, not approved-lamp measurements. H4 rating flux is used before assembly losses; no assembled-bulb flux calibration was performed. The R37 dimensions and all assumed source/optics dimensions are distinguished in `docs/sealed-beam-v2.md`.
