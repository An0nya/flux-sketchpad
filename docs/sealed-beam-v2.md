# Sealed beam v2: source mounting and complete flute geometry

Experimental, not an approved headlamp design. `sealed-beam-v1` is unchanged. Its four saved examples have only their source-preset label corrected; their emitter geometry and optical surfaces are unchanged.

## Choose the source explicitly

- `sealed-beam-assumed-low` / `sealed-beam-assumed-high`: **ASSUMED** transverse sealed-beam filaments. The H4 lengths and nominal flux are proxies, not sourced dimensions for a 6014, H6024 or 4000 burner. No H4 cup, black tip or bulb glass is implied.
- `h4-low` / `h4-high`: the existing **bare axial filament** presets, unchanged for old scenes and other solvers.
- `h4-assembly-low` / `h4-assembly-high`: axial filaments whose cup, tip and glass are generated by v2 with `Bulb parts = Auto`. Outside v2 these presets are still just filaments. `Bulb parts = H4` explicitly adds the assembly to any chosen source; `None` removes it.

The fixed lamp's `Filament shield (direct-light cap)` remains a separate setting. It is neither the H4 internal dipping cup nor the opaque bulb tip. Cup, tip and glass each have their own toggle. The physical cup remains in the assembly when the high filament is lit. With Source setup = H4, changing the beam selects the other filament inside the same mounted bulb; the bulb body does not jump to keep the filament centre fixed.

## Sources and dimension ledger

Web search retrieved UN R37 H4/1–H4/4 in the official [2010 EUR-Lex publication](https://eur-lex.europa.eu/legal-content/EN/TXT/?uri=CELEX:42010X1113(01)). The requested [UNECE Rev.7 PDF](https://unece.org/fileadmin/DAM/trans/main/wp29/wp29regs/R037r7e.pdf) returned HTTP 403; it was not silently treated as read. The official [Australian government reproduction of R37](https://www.legislation.gov.au/F2006L03254/asmade/2006-09-29/text/original/epub/OEBPS/document_1/document_1.html) supplied inspectable [shield](https://www.legislation.gov.au/F2006L03254/asmade/2006-09-29/text/original/epub/OEBPS/document_1/image.133.png) and [filament drawings](https://www.legislation.gov.au/F2006L03254/asmade/2006-09-29/text/original/epub/OEBPS/document_1/image.134.png). That older reproduction numbers its filament drawing H4/4 and table H4/6; the EUR-Lex version combines the drawings in H4/3 and table in H4/4.

R37 says: **“The drawing is not mandatory with respect to the design of the shield.”** H4/1 requires the obscuration to reach the **“cylindrical part of the bulb”** and overlap the shield in side view. These are constraints, not a manufacturer CAD drawing. Numeric geometry not determined by them is marked below.

Coordinates in this table are bulb-local: axial distance from the seating reference plane, increasing toward the tip; vertical height from shield plane HH. The bulb reference axis and reflector axis are different references.

The glass is a closed hollow shell: inner/outer cylinder, inner/outer front, exact rear annulus. Each air/glass normal is oriented explicitly. The engine applies its fixed 0.96 transmission per interface; wall, index and transmission are modelling assumptions. V2 requests 12 interactions with bulb glass so a reflected ray can cross the bulb wall on both journeys and then cross the cover. The cup and tip absorb; they do not simulate metal reflections.

## Mounting and source experiments

World axes: +x forward, +y left, +z up. A rightward source displacement is **negative y**. Azimuth 0° is axial; 90° is transverse; elevation tilts the filament and roll rotates the bulb assembly around it.

`Source adjustment = FIXED OPTICS` is the default. The world reflector focus (`focusX/Y/Z`, default origin) and the **design** filament offset (`lowFwd/Left/Up`) define the generated optics. Actual source position/orientation is independent, stored in the existing `scene.source` fields. The visible `sourceFwd/Left/Up/Az/El/Roll` settings edit those fields. Source controls also work normally. Editing them preserves every reflector, lens and lamp-cap surface and retraces; only source-attached bulb parts move. With tuning off, Rebuild uses the same fixed focus and design source, so it also preserves those optics. Explicitly enabling the tuner and rebuilding intentionally redesigns the flutes for the current emitter. Editing design offsets is an optical design change and requires Rebuild.

`Rebuild optics relative to source (v1)` is the alternative: source edits mark the design stale and the next solve moves its focus with the source. In this mode use the ordinary Source position controls; a source-relative focus cannot provide an independent displacement experiment. Fixed-mode offset fields are intended for fixed mounting.

Assumptions in the supplied scenes:

| Source | High centre relative to focus | Low centre / design offset relative to focus | Orientation |
|---|---|---|---|
| Assumed sealed beam | (0,0,0) | (0,+1.5,+2.5) mm | transverse; **ASSUMED** |
| H4 assembly | (0,0,0) | (+6.7,0,+1.4) mm | axial. Putting the driving centre at focus is **ASSUMED**; relative filament displacement follows the nominal R37 dimensions above |

Focal lengths 25 / 20 mm, reflector clear radii 85 / 69.5 mm (7″ / 5¾″), reflector ideality, cover index 1.50 and all flute parameters remain **ASSUMED**. H4 fixture clearance is explicitly zero because the real cup lies close to the filament; this is stored in those scenes, not a global clearance change. An H4 assembly added to a scene with a large keep-out can correctly report a clearance violation.

Source settings are a UI/CLI convenience, not an extension of solver output: the scene hook `RF.SolverHooks['sealed-beam-v2'].prepareScene(scene, settings, changedKeys)` (= `RF.SealedBeamSource.adjustSource`; reached through `RF.Solvers.prepareScene`, used by `flux.js solve` and the page) updates ordinary source fields **before** solving. Direct solver callers supply their desired `input.source` as usual. In the page, fixed source edits go through the controller and trigger a trace without launching the solver. `flux.js solve --set sourceFwd=…` applies the same pose change before rebuilding against the fixed design reference.

### The review's placement regression

`node tools/sealed-beam/v2-bench.js placement` copies the old saved 7″ low-beam optical surfaces without solving, rotates the existing incomplete filament to axial, then traces each pose with `node tools/flux.js trace … --rays 2000000 --spec fmvss-lb2m,fmvss-lb2v`.

Observed LB2M pass/fail/unsure: origin **14/7/1**, (+1,−0.5,+0.5) **19/3/0**, (+1,+0.5,+0.5) left control **14/7/1**. The same three right-shift failures remain: `4U 8L`, `1.5U 1R to R`, `0.5U 1R–3R`.

**Coordinate correction:** the saved v1 reflector's focus is (0,−1.5,−2.5), not the origin. Thus the review's reproduced “at focus” row is actually an origin-source row. The automated regression names it accordingly; a separate ray-path check starts at the true focus and verifies parallel reflection. These placement results deliberately use the **old incomplete H4 filament**, not the new assembly or a correct installation claim.

## Lens geometry

Each flute is a rectangular **region**, with an independent height. `Variable-width rectangles` expands or contracts the column widths toward the rim (`widthRatio`); changing region area reallocates actual incident flux, without changing any ray's weight. Uniform rectangles and square regions remain available.

`Curved` integrates a varying transverse slope into a parabolic flute profile. Its boundary slopes aim at the region target ± `curveSpread`. The profile is sampled by `curveSteps` planar strips (default 4), so rays across **one** flute leave at different angles. This is an approximation to curved glass, not an analytic curved surface or a measured historical profile. Use more strips to check discretisation sensitivity. `Planar` and zero spread retain the simpler comparison.

The clear aperture is a convex 48-sided polygon. Every strip is clipped against it. Neighboring projected edges are matched; differences in their heights get riser faces. When the height order reverses along an edge, the edge is split at the crossing first; every resulting face is a convex triangle. Perimeter faces connect the inner profile to the outer plane. Plain cover glass likewise includes its cylindrical perimeter. `Trace connecting and perimeter faces = off` exposes the incomplete approximation for comparison.

The complete inner profile starts beyond the reflector rim. If the available envelope depth cannot contain all the sag, all sag is scaled down and the solver notes it; with less than 3 mm cover room it reports an error. No scene or solver API change is required. Refracting and absorbing parts do not count against the reflecting-facet budget.

## Tuning and measurements

All pattern parameters are explicit, including saved high-beam values. Selecting a filament does not silently reinterpret values equal to another beam’s defaults. The scene generator supplies the separate high-beam starting pattern.

The golden-index target scatter uses the fractional part, including for negative flute indices, so the spread bounds are honoured. V1’s negative-remainder behavior is unchanged.

The seeded tuner varies the 16 aim/zone parameters plus within-flute spread and rim/centre width ratio. In `tuneAim = frozen` it obtains the starting incumbent's aim, judges **every** candidate at that same aim, then runs the full aim procedure once for the final candidate. Winners do not get extra aim searches. `scan` remains selectable for comparison; async traces follow the identical rule. Tuning uses a fixed trace seed and a separate seeded mutation sequence; `tuneSeconds = 0` is deterministic.

LB2M and LB2V are judged separately, with their own aim procedure and limits. The low-beam examples are tuned against **LB2M**; their LB2V results are a separate assessment of the same optics. A higher pass count is not compliance, and single-seed differences of a row need replication.

All photometric numbers come from `node tools/flux.js solve|trace`. Bench phases:

```sh
node tools/sealed-beam/v2-bench.js placement
node tools/sealed-beam/v2-bench.js bare
node tools/sealed-beam/v2-bench.js lens --lamps 7,5.75 --beams low,high --models sealed,h4 --evals 150 --tuneRays 100000
```

Raw trace rows, solve notes, settings and exact commands live in `tools/sealed-beam/v2-results/`. The SB2 report in `.claude/briefs/reports/` contains measurement tables and test output. New example names start `sealed-beam-v2-`; the four v1 examples stay on v1.

Node checks: `node tests/sb2-node.js` (also included by `node tests/regress-node.js`). Page/worker checks, **not run by the builder**: serve this worktree on 8734, then `node tests/regress/SB2-sealed-beam-v2.js 8734`.
